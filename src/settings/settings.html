飞书

扫码自动配置 飞书会自动创建应用、开好权限与事件订阅，并把凭据填回这里
正在获取二维码…
在浏览器中打开授权页
用飞书扫码，或点上面的链接在已登录的浏览器里确认。
走 WebSocket 长连接，不需要公网地址或内网穿透。
手动配置时的顺序不能颠倒：先发布一次版本 → 再回来填凭据并保存（进程会建立长连接）→ 然后才能在开放平台保存「长连接接收事件」→ 最后再发一次版本。飞书保存长连接时会实时探测连接是否在线，顺序错了会提示「未检测到应用连接信息」。另外别忘了设置「可用范围」，否则飞书里搜不到机器人。

Telegram

在 Telegram 里找 @BotFather 发 /newbot，按提示起个名字， 它会回一串形如 123456:AA... 的 token，粘到这里即可。只需这一项—— 走长轮询，不需要公网地址，也不用在任何后台配置权限或审核。
白名单填 Telegram 的数字用户 ID（和飞书的 open_id 放在同一个列表里）。 不知道自己的 ID 就直接给机器人发一句话，它会把你的 ID 回给你。

谁可以用

只有这里列出的人能驱动 agent，群里也一样。留空则谁都不能用。
能给这个机器人发消息的人，等于能在这台电脑上执行命令。白名单请只放你自己和确实信任的人。

工作目录

聊天里用 /cd 名称 切换，/ls 查看列表。agent 只在这些目录里活动。

权限

审批卡片会显示 agent 要执行的具体命令和它给出的理由，可以选「允许一次」「本会话内都允许」或「拒绝」。 注意 macOS 上「工作目录内可写」的越界拦截并不可靠，真要拦住请用只读。
